# Network Auto Backup System - Sri Lanka

A Python project that automates Cisco router configuration backups.

### What it does
This script automates backups for multiple branch routers (Colombo, Kandy, Galle). It generates backup files with automatic date naming.

### Tech I Used
- Python 3
- Cisco Packet Tracer
- Networking Basics (IP, Ping, SSH)

### How to Run
python backup.py

### My Learning
I learned how Packet Tracer is an isolated network and how to build automation logic to handle multiple devices at once. Next step is to use Netmiko for real SSH connections.
